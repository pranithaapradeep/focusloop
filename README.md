# 🎯 FocusLoop

A free web application that allows users to loop YouTube videos for focused learning and practice.

## ✨ Features

- **YouTube Video Looping**: Paste any YouTube URL and loop the entire video or specific sections
- **AB Loop**: Set custom start and end times for precise looping
- **Flexible Time Input**: Support for both seconds (90) and minutes format (1:30)
- **Keyboard Shortcuts**: Space (Play/Pause), L (Toggle Loop), R (Reset Loop)
- **Note Taking**: Built-in notes area for taking notes while watching
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Clean UI**: Modern, light-themed interface

## 📱 How to Use

1. **Load Video**: Paste a YouTube video URL and click "Load Video"
2. **Set Loop Points**: 
   - Enter start time (e.g., `90` or `1:30`)
   - Enter end time (e.g., `165` or `2:45`)
3. **Enable Loop**: Click "Enable Loop" to start AB looping
4. **Full Video Loop**: Click "Loop Full Video" for complete video looping
5. **Take Notes**: Use the notes section to jot down important points

## ⌨️ Keyboard Shortcuts

- `Space` - Play/Pause video
- `L` - Toggle loop on/off
- `R` - Reset loop settings

## 🏃‍♂️ Running Locally

1. Clone the repository:
```bash
git clone https://github.com/your-username/focusloop.git
```

2. Open `index.html` in your web browser

That's it! No build process or dependencies required.
